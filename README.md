# 💻 Digital Verification Diploma

Welcome to the official repository for the **Digital Verification Diploma**. This diploma program delivers an in-depth journey through advanced digital verification, with a focus on practical, industry-relevant methodologies using SystemVerilog, Verilog, and FPGA-based verification flows.

---

## 🗂️ Diploma Content Overview

### 📘 Foundations of Digital Design Verification
- Overview of classical digital design and the modern verification workflow.
- Core concepts in HDLs with emphasis on SystemVerilog and Verilog.
- Setting up verification environments, testbench basics, and simulation principles.

### ⚙️ Combinational & Sequential Logic Verification
- Verification of combinational and sequential circuits.
- Testbench creation for counters, shift-registers, FSMs, and memory modules.
- Techniques for assertion-based and coverage-driven verification.

### 🔬 Static Checks & Linting
- Automated static analysis using industry tools such as QuestaLint.
- Introduction to Clock Domain Crossing (CDC) and Reset Domain Crossing (RDC) challenges.
- Formal verification practices and methodology.

### 🧪 Simulation & FPGA Prototyping Flow
- Running simulation environments and creating test automation using TCL scripts.
- Synthesis validation on Vivado, integrating IP cores, managing constraints.
- Bringing up complete designs on the Digilent Basys 3 FPGA board.

### 🔄 Advanced Verification Topics
- Deep dive into CDC/RDC analysis and verification using Siemens QuestaCDC and QuestaRDC.
- Low-power design, power/voltage domain crossing, and static timing verification.
- Overview of memory and communication protocol verification.

### 🏆 Final Projects & Case Studies
- End-to-end digital design verification projects synthesizing all skills learned.
- Implementation and verification of DSP and communication modules.
- Real-world-inspired assignments and project documentation.

## 🛠️ Tools & Software Used

- **VS Code** (Hardware design and verification development)
- **Xilinx Vivado** (Synthesis, implementation, and bitstream generation)
- **Digilent Basys 3 FPGA Board** (Artix-7 based)
- **Siemens QuestaSim** (Simulation)
- **Siemens QuestaLint, QuestaCDC, QuestaRDC** (Advanced verification and design checks)
- **Tcl Scripting** (Simulation and flow automation)
